# Guia de usuario

## Administrador

1. Crear organizacion y usuarios.
2. Asignar roles: `admin`, `evaluator`, `viewer`.
3. Activar MFA en produccion.
4. Revisar alertas criticas y bitacoras de auditoria.
5. Aprobar reportes antes de enviarlos a direccion.

## Evaluador

1. Registrar activos de TI: hardware, software, datos y personas clave.
2. Asignar criticidad de 1 a 5.
3. Completar evaluacion NIST CSF 2.0 por activo.
4. Revisar puntaje, nivel de riesgo y alertas.
5. Generar reporte IA, editar contenido y enviar a aprobacion.

## Lector ejecutivo

1. Abrir dashboard.
2. Revisar distribucion de riesgos y alertas recientes.
3. Descargar o consultar reportes aprobados.
